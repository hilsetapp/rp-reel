# Галерея пресетов

Пресет - это json-файл с настройками окна нарезки:

```json
{
  "name": "base",
  "title": "Обычная нарезка",
  "note": "Окно 10 секунд до и после события, склейка без перекодирования.",
  "pre": 10,        // секунд до события
  "post": 10,       // секунд после события
  "minLen": 3,      // минимальная длина клипа
  "mergeGap": 2,    // щель меньше этой - клипы сливаются
  "maxClips": 0,    // 0 = без лимита, иначе берутся самые событийные
  "reencode": false,
  "extraArgs": []
}
```

## Свой пресет

1. Скопируй `base.json`, поменяй поля.
2. Положи в папку `templates` рядом с `rp-reel.exe`.
3. Приложение подхватит его: кнопка пресета листает и твои тоже.

## Что значит reencode

`reencode: false` - нарезка без перекодирования (`-c copy`),
мгновенно даже для 4K, но кадр обрезается по ключевым.

`reencode: true` - можно добавить фильтры в `extraArgs`,
например вертикаль 9:16 (смотри `vk-vertical.json`).
Медленнее, зато кадр меняется по-настоящему.
