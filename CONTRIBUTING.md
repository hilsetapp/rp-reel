# Как помочь

Привет! Проект молодой, принимается всё, что делает нарезку полезнее.

## Идеи, которые сейчас нужны

- плагины для других серверов: MTA, Oxen, Diamond RP;
- автосинхронизация видео и журнала по звуку;
- карта событий по координатам из журнала;
- пресеты под конкретные мессенджеры и площадки.

## Правила

1. Пиши по-русски, коротко и по делу.
2. Один коммит - одна идея.
3. Тесты: `go test ./internal/...`
4. Формат: `gofmt -l .` должен молчать.
5. README на русском первым, английский рядом.

## Структура

- `internal/evtlog` - чтение журнала rpreel.jsonl
- `internal/timeline` - события в окна нарезки
- `internal/stats` - сводка
- `internal/cut` + `internal/ffmpeg` - вырезка и склейка
- `internal/template` - галерея пресетов
- `internal/gui` - окно на Gio
- `plugins/` - включения для серверов
- `cmd/rp-reel` - GUI, `cmd/rp-reel-cli` - консоль
